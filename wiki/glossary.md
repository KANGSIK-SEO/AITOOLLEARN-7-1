# 용어 사전

| 용어 | 쉬운 뜻 | 이 프로젝트에서 |
|---|---|---|
| CC0 | "아무 조건 없이 마음대로 써도 된다"는 표시. 상업 이용·수정 가능, 출처 표시 의무 없음 | 유일하게 허용하는 라이선스 ([권리 판단](rights.md)) |
| 퍼블릭 도메인 | 저작권이 끝났거나 없는 작품 | 기관이 작품마다 밝힌 것만 믿는다 |
| PDM | 퍼블릭 도메인 마크. CC0와 비슷하지만 법적으로 다르다 | Rijksmuseum 보류 이유 |
| 공공누리 1유형 | 한국 공공저작물 표시. **출처 표시 의무**가 있어 CC0가 아니다 | e뮤지엄 보류 이유 |
| FTS5 | SQLite 안의 전문 검색 기능 (책 뒤 색인처럼 단어로 빨리 찾기) | `artworks_fts` ([작품 검색](search.md)) |
| Turso | 인터넷으로 쓰는 SQLite 서비스 | 사용자 DB ([데이터베이스](database.md)) |
| 서버리스 | 서버를 직접 켜 두지 않고, 요청이 올 때만 잠깐 실행되는 방식 | Vercel |
| scrypt | 일부러 느리게 만든 비밀번호 해시 방식 (무차별 대입을 어렵게) | [로그인과 보안](auth.md) |
| HMAC 서명 | 비밀 키로 만든 "도장". 내용이 바뀌면 도장이 안 맞는다 | 로그인 토큰, 근거 기록 |
| 폴백 | 주 수단이 실패하면 쓰는 대체 수단 | gpt-6-astra → solar-pro4 ([AI 호출](ai-llm.md)) |
| Wayback Machine | 인터넷 아카이브의 웹페이지 보관 서비스 | [권리 근거 기록](records.md) |
| PWA | 웹사이트를 앱처럼 홈 화면에 설치하는 기술 | [화면](frontend.md) |
| 서비스워커 | 브라우저 안에서 파일을 캐시해 두는 작은 프로그램 | `sw.js` |
| 캐시 무효화 | 옛 파일 대신 새 파일을 받게 만드는 것 | `?v=해시` |
| Datalog | "이 조건이면 후보다" 식의 규칙으로 데이터를 찾는 언어 | 온디바이스 추천 |
| 레이트 리밋 | 일정 시간 안의 요청 횟수 제한 | [가디언](guardian.md) |
| merge commit | PR을 합칠 때 커밋 기록을 그대로 두고 "합쳤다" 기록을 하나 더 남기는 방식 | [팀과 작업 방식](team-process.md) |
