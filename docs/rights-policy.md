# 권리 판단 규칙 (Rights Policy)

> 이 문서가 **설계도**다. `app/rights.py`(판단 규칙 코드), `data/art.db`(권리 데이터),
> `app/records.py`(권리 근거 기록)는 모두 이 문서를 그대로 옮긴 것이다. 규칙을 바꾸려면 **이 문서부터** 고치고 코드를 맞춘다.

**우리가 파는 것**: "써도 된다는 보증"이 아니라, **써도 되는지 확인하는 수고를 대신하고 그 근거를 날짜와 함께 보관해 주는 서비스**.
우리는 공신력 있는 기관이 아니므로 인증·보증·확인서라는 말을 쓰지 않는다. 문서 이름은 **"권리 근거 기록"**이다.

## 0. 원칙

1. **애매하면 넣지 않는다.** 서비스 이름이 "저작권 걱정 없는"이다. 한 작품이라도 틀리면 서비스 전체를 믿을 수 없게 된다.
2. **우리가 판단하지 않는다. 기관이 작품 단위로 밝힌 것만 옮긴다.** 연도·작가 사망년도로 "아마 퍼블릭 도메인일 것"이라고 추정하지 않는다.
3. **근거를 남긴다.** 어떤 기관의 어떤 필드가 어떤 값이었는지, 언제 확인했는지를 작품마다 기록하고 권리 근거 기록에 그대로 보여준다.
4. **보증이 아니라 기록이다.** 권리 근거 기록은 "기관이 그날 이렇게 공개했다"는 기록이지, 모든 사용을 보증하는 문서가 아니다 (§4 주의사항).
5. **제3자 증거를 붙인다.** 우리 직인보다 인터넷 아카이브(archive.org) 같은 제3자 보관본이 더 믿을 만하다.

## 1. 공급원(기관) 허용 기준

기관을 허용 목록에 넣으려면 아래 **전부**를 만족해야 한다.

| # | 기준 | 이유 |
|---|---|---|
| S1 | 기관이 공식 정책 페이지에서 해당 이미지를 **CC0**로 공개한다고 밝힌다 | "퍼블릭 도메인 마크(PDM)", "출처 표시 조건부" 등은 CC0가 아니다 |
| S2 | API(또는 공식 데이터셋)가 **작품 단위**로 CC0/퍼블릭 도메인 여부를 필드로 준다 | 기관 전체가 아니라 작품마다 다르다. 저작권 남은 작품이 섞여 있다 |
| S3 | 이미지 URL이 기관 공식 도메인이다 | 제3자 미러는 원본과 다를 수 있다 |
| S4 | 작품마다 기관 공식 상세 페이지 URL이 있다 | 사용자가 직접 재확인할 수 있어야 한다 |
| S5 | 팀원 1명이 정책 페이지를 직접 열어 확인하고, 확인일을 아래 표에 적었다 | 기관 정책은 바뀐다 |

### 기관 현황

| 기관 | 코드 | 상태 | 작품 단위 근거 필드 | 비고 |
|---|---|---|---|---|
| The Metropolitan Museum of Art | `met` | ✅ 허용 | `isPublicDomain = true` | 파일럿(작게 검증) 대상 |
| Art Institute of Chicago | `aic` | ✅ 허용 | `is_public_domain = true` | 이미지는 IIIF 서버 (헤더 필요 → 서버 프록시) |
| Cleveland Museum of Art | `cma` | ✅ 허용 | `share_license_status = "CC0"` | API 키 불필요, `cc0` 필터 제공 |
| National Gallery of Art (워싱턴) | `nga` | ⏸ 보류 | 공식 오픈데이터(CSV)의 open access 이미지 표시 | API가 아니라 데이터셋 — 수집 방식 설계 후 S2·S5 확인 |
| Smithsonian Open Access | `si` | ⏸ 보류 | `usage.access = "CC0"` | API 키(api.data.gov) 발급 필요. 기관 내 박물관마다 작품 성격이 달라 S5 확인 후 추가 |
| Rijksmuseum (암스테르담) | `rijks` | ⏸ 보류 | — | 이미지에 CC0가 아니라 **퍼블릭 도메인 마크(PDM)**를 다는 경우가 있어 S1 확인 전에는 넣지 않는다 |
| 국립중앙박물관 e뮤지엄 | `emuseum` | ⏸ 보류 | 공공누리 유형 | **공공누리 1유형은 CC0가 아니다** — 출처 표시 의무가 있다. 넣으려면 "출처 표시 필요" 라이선스를 별도로 다루는 규칙(§3 L2)과 기록 문구를 먼저 만든다 |

> 보류 기관은 코드에 등록만 돼 있고 검색 결과에는 절대 나오지 않는다 (`app/rights.py`의 `enabled=False`).

## 2. 작품 판단 규칙

검색 결과·권리 근거 기록에 나가는 모든 작품은 아래를 순서대로 통과해야 한다. 하나라도 실패하면 **검색 결과에서 뺀다** (R5만 예외).

| # | 규칙 | 실패 시 |
|---|---|---|
| R1 | 출처 기관이 허용 목록(§1 ✅)에 있다 | 제외 |
| R2 | 기관이 작품 단위로 퍼블릭 도메인/CC0라고 밝혔다 (`is_public_domain = 1`) | 제외 |
| R3 | 우리 DB의 라이선스가 `CC0`이다 | 제외 |
| R4 | 원본 이미지가 기관 공식 도메인이다 | 제외 |
| R5 | 권리 확인일(`collected_at`)이 **365일 이내**다 | 결과에는 두되 기록에 "재확인 필요"로 표시 |
| R6 | 기관 공식 상세 페이지 URL이 있다 | 제외 |

## 3. 라이선스 종류

| 코드 | 의미 | 현재 |
|---|---|---|
| L1 `CC0` | 조건 없이 상업적 이용·수정 가능, 출처 표시 의무 없음 | 유일하게 허용 |
| L2 출처표시형 (공공누리 1유형, CC BY 등) | 상업 이용 가능하나 출처 표시 의무 | **미지원** — 기록·카드에 의무를 표시하는 기능을 만든 뒤에만 허용 |
| 그 외 (PDM, 비영리, 변경금지, 문의 필요 등) | — | 영구 제외 |

## 4. 권리 근거 기록에 항상 적는 주의사항

CC0는 **저작권**에 대한 것이다. 아래는 별개이므로 기록에 항상 적는다.

0. 이 기록은 기관이 공개한 정보를 발급 시점 그대로 옮긴 것이며, 공식 인증서나 법률 자문이 아니다.

1. 작품에 **사람의 얼굴·이름**이 나오면 초상권·퍼블리시티권 문제가 따로 있을 수 있다.
2. 작품 속 **상표·로고**는 상표법으로 따로 보호될 수 있다.
3. 기관 이름·로고를 써서 **기관이 보증·후원하는 것처럼** 보이게 하면 안 된다.
4. 출처 표시는 의무가 아니지만, 기관들은 출처 표시를 **권장**한다 (기록의 "출처 표기 예시" 사용).
5. 중요한 상업 프로젝트는 사용 직전 기관 페이지를 다시 확인한다.

## 5. 권리 근거 기록 구성

발급: 카드의 **"근거 기록"** 버튼 → `POST /api/records` → `/records/{기록 번호}` (인쇄/PDF 저장 가능한 한 장)

1. **발급 시점 그대로 보관**: 발급하는 순간의 작품·기관·근거·판정 결과를 통째로(스냅숏) 저장한다.
   나중에 기관이 표시를 바꿔도 기록은 바뀌지 않는다. 오늘 다시 판단한 결과가 다르면 기록 아래에 "참고"로만 따로 적는다.
2. **제3자 보관본**: 발급할 때 인터넷 아카이브(Wayback Machine)에 ① 기관 작품 페이지 ② 근거 필드가 담긴 기관 API 응답을
   저장하고, 그 보관본 링크(보관 시각 포함)를 기록에 넣는다. 실패하면 기록 페이지의 "다시 보관하기"로 재시도한다.
3. **변조 확인**: 기록 번호·발급 시각·스냅숏으로 서명값을 만들어 함께 저장하고, 기록을 열 때마다 대조해 "기록 무결성"을 표시한다.
4. 담기는 내용: 작품 정보, 권리 근거(기관·근거 필드·정책 페이지·작품 페이지·원본 이미지·권리 확인일), 제3자 보관본,
   판단 결과(R1~R6), 출처 표기 예시, 주의사항(§4), 기록 번호, 발급 시각.
5. 판단 규칙을 통과하지 못한 작품(blocked)에는 발급하지 않는다.

## 6. 작게 검증하기 (파일럿)

환경 변수 `ALLOWED_SOURCES=met`을 설정하면 **MET 한 곳의 CC0 작품만** 검색·더 보기·권리 근거 기록에 나온다.
이 상태로 디자이너·소상공인 5명에게 써보게 하고, **첫 질문은 하나**다:

> "이 기록이 있으면 안심하고 쓰시겠어요?"

"그렇다"가 나오면 그다음에 가격을 붙인다. 아니라면 무엇이 빠졌는지 듣고 이 문서(§4·§5)부터 고친다.
